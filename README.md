# ChefsApps

Chefs App 
GitHub Repo link: https://github.com/PhulusoN/ChefsApps
YouTube video link:
Chef apps is an application built using react native, the main purpose of this app is to help chefs manage their menu in a faster way rather than using pen and papers, this helps them add, delete and update the menu items at ease they also get to see the customers reviews of each item in the menu so they know what to improve on and what’s their best seller

The application is easy to use because  it does tell the chef what  to input in each section.
For example the add new item form, the app guides them on how to add the items so they dint mix things .
